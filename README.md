## 📥 วิธีติดตั้ง

### ขั้นตอนที่ 1 — ดาวน์โหลด Extension

```
git clone https://github.com/FiwFlash/Bulk-Print-Redesign.git
```

หรือกดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์

### ขั้นตอนที่ 2 — ติดตั้งใน Chrome

1. เปิด Chrome แล้วไปที่ `chrome://extensions/`
2. เปิด **Developer mode** (มุมขวาบน)
3. กดปุ่ม **Load unpacked**
4. เลือกโฟลเดอร์ที่ดาวน์โหลดมา (โฟลเดอร์ที่มีไฟล์ `manifest.json`)
5. Extension จะปรากฏใน toolbar ของ Chrome ✅

### ขั้นตอนที่ 3 — ขอ Gemini API Key (ฟรี)

1. เปิด [Google AI Studio](https://aistudio.google.com/apikey)
2. กด **Create API key**
3. คัดลอก API Key เก็บไว้

## 🚀 วิธีใช้งาน

### 1. เปิด Extension

คลิกไอคอน **ThaiPost Print** ที่ toolbar ของ Chrome → Extension จะเปิดเป็น **Side Panel** ด้านข้าง

### 2. ตั้งค่า API Key

- วาง **Gemini API Key** ในช่อง `🔑 ตั้งค่าระบบ`
- เลือก **Model** ที่ต้องการ (กด 🔄 เพื่อโหลดรายการ Model)

### 3. กรอกข้อมูล

มี **2 โหมด** ให้เลือก:

#### โหมด A — แยกช่องผู้ส่ง/ผู้รับ (แนะนำ)

- **📦 ข้อมูลผู้ส่ง** — แปะที่อยู่ร้านค้า หรือลากรูปนามบัตรมาวาง (ระบบจำข้อมูลผู้ส่งไว้อัตโนมัติ)
- **👥 ข้อมูลผู้รับ** — ก๊อปแชทลูกค้ามาแปะได้เลย ใส่หลายคนพร้อมกันได้

#### โหมด B — รวมในช่องเดียว

- แปะข้อมูลผู้ส่งและผู้รับรวมกัน — Gemini จะแยกให้เองอัตโนมัติ

> 💡 **เคล็ดลับ**: สามารถ **ลากรูปภาพ** (สลิป, screenshot แชท, นามบัตร) มาวางในช่องได้เลย!

### 4. สั่งวิเคราะห์

กดปุ่ม **✨ วิเคราะห์ข้อมูล** → Gemini AI จะสกัดแยกรายชื่อลูกค้าให้

### 5. ตรวจสอบและแก้ไข

- ระบบจะแสดงข้อมูลผู้ส่งและผู้รับทั้งหมดให้ตรวจสอบ
- กด **🔍 ตรวจสอบ** เพื่อเช็คความถูกต้องของที่อยู่กับฐานข้อมูล
- แก้ไขได้ทุกช่อง (ชื่อ เบอร์ ที่อยู่ รหัสไปรษณีย์)
- เพิ่มลูกค้าเพิ่มเติมได้ด้วยปุ่ม **➕ เพิ่มลูกค้าต่อท้าย**
- เรียกใช้จาก **📒 สมุดจดผู้ส่ง/ผู้รับ** ที่บันทึกไว้ได้ทันที

### 6. ตั้งค่าการพิมพ์

เลือกขนาดกระดาษที่ต้องการ:

| ขนาด | เหมาะกับ |
|---|---|
| **10×10 cm** | สติกเกอร์จ่าหน้ามาตรฐาน |
| **4×6 Shipping Label** | สติกเกอร์ label เครื่องพิมพ์ความร้อน |
| **A6** | กระดาษ A6 |
| **A5** | กระดาษ A5 |
| **A4 2-up** | A4 แบ่ง 2 ใบ/หน้า |
| **A4 จ่าหน้ากล่อง** | A4 แนวนอน สำหรับแปะกล่อง |

### 7. พิมพ์

- กด **เปิดตัวอย่าง / แก้ไข** เพื่อดู Preview และปรับแต่ง (ลากย้ายตำแหน่ง, ปรับขนาดตัวอักษร)
- กด **🖨️ เปิดหน้าต่างพิมพ์** เพื่อพิมพ์ทันที

## ⚙️ เทคโนโลยีที่ใช้

- **Chrome Extension Manifest V3** — Side Panel API
- **Google Gemini AI API** — สกัดข้อมูลจากข้อความ/รูปภาพ (Vision)
- **Vanilla JavaScript** — ไม่พึ่ง framework ใดๆ
- **Chrome Storage API** — บันทึกข้อมูล API Key, สมุดจดที่อยู่, ประวัติ
- **ฐานข้อมูลที่อยู่ไทย** — ตรวจสอบจังหวัด/อำเภอ/ตำบล/รหัสไปรษณีย์ (โหลดจาก GitHub Gist)

## 📝 หมายเหตุ

- ต้องมี **Gemini API Key** จึงจะใช้ฟีเจอร์ AI สกัดที่อยู่ได้ (ขอฟรีได้ที่ [Google AI Studio](https://aistudio.google.com/apikey))
- หากไม่ต้องการใช้ AI สามารถกด **ข้ามไปหน้าตรวจสอบ / กรอกเอง** เพื่อกรอกข้อมูลด้วยตัวเองได้
- ข้อมูลทั้งหมดถูกเก็บไว้ใน **เครื่องของคุณเท่านั้น** (Chrome Storage) ไม่ได้ส่งไปเซิร์ฟเวอร์ใดๆ ยกเว้นการเรียก Gemini API
